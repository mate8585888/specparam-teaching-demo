SpecParam / FOOOF 教学演示包 v1.0
================================

一、这个包解决什么问题
----------------------
初学者不需要在PowerShell中手动输入pip命令，也不需要自己处理虚拟环境。

第一次使用只需要：

1. 双击 01_install.bat
2. 安装成功后，双击 02_run_set_demo.bat
3. 选择一个预处理好的EEGLAB .set文件
4. 自动查看分析结果

安装环境与分析程序相互分离。安装只做一次，以后直接运行分析即可。

二、建议的第一次使用顺序
------------------------
第一步：双击 01_install.bat

程序会在教学包内部创建一个名为“.venv”的独立环境，并自动安装：
- FOOOF 1.1.1
- MNE
- NumPy
- SciPy
- Matplotlib
- pymatreader

这个环境仅属于本教学包，不会主动卸载或升级你其他项目中的Python包。

第二步：双击 03_run_builtin_demo.bat

这一步不需要任何EEG数据。程序会生成一条包含：
- 非周期背景
- 约10 Hz周期峰
- 约20 Hz周期峰

的合成功率谱，并完成一次FOOOF拟合。

只有内置演示能够成功运行，才建议继续分析自己的.set数据。

第三步：双击 02_run_set_demo.bat

在弹出的窗口中选择一个预处理好的.set文件。

如果.set使用外部.fdt保存数据，请确保：
- .set与.fdt位于同一个文件夹；
- 两者文件名保持原来的对应关系；
- 文件能够在EEGLAB中正常打开。

三、教学版脚本做了什么
----------------------
.set数据
→ 读取EEG通道
→ Welch方法计算PSD
→ 在线性功率尺度下平均通道
→ 输入FOOOF
→ 输出非周期参数与周期峰参数

教学版有意只处理“全部EEG通道的平均功率谱”。

这样做的目的不是形成最终论文方案，而是让初学者先看清：
- FOOOF真正的输入是什么；
- 周期和非周期参数从哪里来；
- 拟合图应该怎么看；
- 输出参数文件是什么形式。

四、主要输出文件
----------------
01_FOOOF输入_平均PSD.csv
    两列：频率、线性功率谱。
    这就是FOOOF真正接收的数据。

02_非周期参数.csv
    offset、exponent、R²、error和峰数量。

03_周期峰参数.csv
    每个峰的中心频率CF、峰值功率PW和带宽BW。

04_模型曲线.csv
    原始功率谱、非周期拟合、周期成分和完整模型拟合。

05_频谱参数化拟合图.png
    第一次运行后最应该查看的文件。

README_结果说明.txt
    本次数据、参数和结果的中文摘要。

五、几个必须理解的限制
----------------------
1. FOOOF不能直接处理原始EEG时间序列，它处理的是功率谱。
2. 输入功率必须是线性尺度，不能提前转换成dB或log10。
3. 教学版采用所有EEG通道的平均PSD，不代表正式研究的最终分析单位。
4. 默认拟合2–40 Hz，并使用fixed非周期模型，主要用于第一次试跑。
5. 正式研究不能只看R²，还要检查拟合图、异常峰和参数稳定性。
6. 课程或推文中应把本包定位为“理解分析流程”，而不是“一键生成论文结果”。

六、文件说明
------------
01_install.bat
    一键创建本地环境并安装依赖。

02_run_set_demo.bat
    选择.set文件并运行教学分析。

03_run_builtin_demo.bat
    使用合成功率谱测试安装和拟合。

04_reset_environment.bat
    删除本包内部的.venv环境，用于重新安装。
    不会删除EEG数据和结果。

app/
    教学版程序文件。初学者不需要修改。

advanced/
    放置更完整的多通道脚本。
    第一次学习时可以忽略。

results/
    运行内置演示后自动创建。

error_logs/
    程序失败时自动保存完整错误日志。
    用户不需要复制终端中的长报错，只需发送日志文件。

七、Python要求
--------------
本包优先使用64位Python 3.11，也支持Python 3.9–3.12。

若安装程序提示找不到兼容Python：
1. 安装64位Python 3.11或3.12；
2. 安装时勾选“Add Python to PATH”；
3. 重新双击01_install.bat。

八、用于教学时的推荐安排
------------------------
课堂正文只展示最核心的FOOOF代码和拟合图。

本教学包作为课后练习，让学员完成：
1. 运行内置示例；
2. 运行自己的一个.set文件；
3. 找到FOOOF输入PSD；
4. 找到offset和exponent；
5. 找到周期峰的CF、PW和BW；
6. 对照拟合图理解每个参数。

版本：v1.0
用途：零基础教学试跑，不作为正式研究方案。
